# ☕ Java Learning Repository

Questa repository raccoglie una serie di progetti sviluppati durante un percorso di studio su:

* Java
* Hibernate
* Spring Framework
* Spring Boot

L’obiettivo è consolidare le competenze nello sviluppo backend, passando dalle basi fino alla creazione di applicazioni complete.

---

## 📚 Argomenti trattati

### 🔹 Java

* Programmazione ad oggetti (OOP)
* Collezioni (List, Set, Map)
* Eccezioni
* Stream e Lambda
* Struttura di un progetto Java

---

### 🔹 Hibernate (ORM)

* Mapping tra classi Java e database
* Entity e annotazioni (`@Entity`, `@Id`, ecc.)
* Relazioni:

  * OneToOne
  * OneToMany
  * ManyToMany
* Query (HQL / Criteria)
* Gestione della sessione

---

### 🔹 Spring Framework

* Dependency Injection (IoC)
* Bean e configurazione
* Architettura a livelli
* Gestione dei servizi

---

### 🔹 Spring Boot

* Creazione di applicazioni standalone
* REST API
* Controller (`@RestController`)
* Configurazione semplificata
* Integrazione con database

---

## 🚀 Come usare questa repository

1. Clona il progetto:

```bash id="4gmnxy"
git clone git@github.com:kr7ek/java-ee.git
```

2. Apri uno dei progetti con il tuo IDE (es. Eclipse o IntelliJ)

3. Segui le istruzioni specifiche all’interno di ciascun progetto
